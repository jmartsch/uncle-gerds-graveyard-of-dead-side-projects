    About this project

    A personal agent that turns abandoned GitHub repos into graves, lets Uncle Gerd judge them and tries to bring them back to life. Built for Hacksgiving 2026.

    The Fly.io Sprite

    The whole app lives on one Fly.io Sprite, ugm-museum: web page, Node API and curator. It has a public URL and sleeps when nobody visits.

    Connectors

    Calls to these four services go through the Sprites connector gateway, so no provider API key is stored on a Sprite.

    GitHub
    Finds the dead: repos, READMEs, last commits, open issues.
    TypeSafeAI (Jev)
    Judges them: revival odds, "worth it" and Uncle Gerd's mood as typed decisions.
    Ollama Cloud
    Gives Uncle Gerd his voice: plaque, cause of death and commentary.
    Anthropic
    The surgeon: headless Claude Code reaches Claude without a key on the exhibit Sprite.

    Sprites features

    One Sprite per revival
    Each patient gets a fresh, isolated Sprite, created with the Sprites SDK (@fly/sprites).
    Checkpoint and restore
    A checkpoint before surgery. If an attempt fails, it is restored before the next one.
    Services and public URLs
    A revived project runs as a service with its own URL and wakes up on a visit.
    Tasks API
    Keeps the museum Sprite awake during scans and revivals.

    Tech

    Node.js 24 without a web framework, vanilla JavaScript and CSS, Phaser 3, pixel art drawn in code, Web Audio.
